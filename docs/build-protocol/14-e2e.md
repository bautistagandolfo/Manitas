# Fase 14 — E2E realista

> **Antes de empezar:** verificá que la Fase 13 esté VERDE en
> `state/STATUS.md`. Si no, DETENÉTE.

Quiero realizar una prueba End-to-End del sistema completo simulando el
uso real de un local de ropa.

NO evalúes únicamente módulos individuales.

Evaluá flujos completos de negocio.

Usá los flujos reales definidos por los requisitos del sistema.

Incluí, cuando corresponda:

1. Login
2. Apertura de caja
3. Alta de producto
4. Entrada de stock
5. Venta
6. Actualización de stock
7. Registro de pago
8. Devolución
9. Reingreso de stock
10. Cierre de caja
11. Consulta de reportes

También probá:

- operación cancelada
- operación duplicada
- producto inexistente
- stock insuficiente
- usuario sin permisos
- pérdida de conexión
- refresh durante operación
- doble envío
- operaciones simultáneas

Para cada escenario verificá:

- resultado visible
- estado persistido
- stock
- caja
- auditoría
- permisos
- consistencia

No consideres exitoso un escenario únicamente porque la UI muestra un
mensaje correcto.

Verificá el estado real persistido.

Documentá cualquier discrepancia.

NO modifiques código salvo que un framework de testing requiera archivos
específicos de test.

---

> **Al finalizar:** guardá el resultado en `state/reports/e2e-<fecha>.md` y
> agregá una fila a `state/STATUS.md` (Fase 14, VERDE/BLOQUEADO).
